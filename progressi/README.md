# Progressi

Un file per passo (`01.md`, `02.md`, ...) con tre sezioni: **Prima** (la risposta alla domanda
d'apertura, scritta prima di leggere), **Oggetto** (la checklist, la tabella, la rubrica che il
passo produce), **Dopo** (cosa è cambiato rispetto a «Prima»). Il passo è chiuso quando lo si sa
raccontare in tre frasi senza rileggere.
